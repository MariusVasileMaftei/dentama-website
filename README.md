# Dentama - Cabinet Stomatologic

Platformă web pentru cabinetul stomatologic **Dentama**, proiectată modular pentru a oferi o experiență modernă și accesibilă pacienților.

---

## Stadiul Actual (Frontend)

În prezent, proiectul include o interfață web statică, complet responsive și structurată modular.

### Funcționalități implementate:
- **Acasă** (`index.html`) - Prezentare generală a cabinetului.
- **Servicii** (`servicii.html`) - Detalierea tratamentelor stomatologice oferite.
- **Echipa Medicală** (`echipa.html`) - Prezentarea personalului de specialitate.
- **Tarife** (`tarife.html`) - Lista transparentă de prețuri și servicii.
- **Cazuri Clinice** (`cazuri.html`) - Prezentare de studii de caz și rezultate.
- **Despre Noi** (`despre.html`) - Misiunea și valorile clinicii.
- **Contact & Programări** (`contact.html`, `programare.html`) - Interfețe dedicate pentru solicitarea de programări și contact direct.

---

## Tehnologii Utilizate

### Frontend
- **HTML5** - Structură semantică.
- **CSS3** - Design responsive și sistem de stilizare custom (Champagne Gold theme).
- **JavaScript (Vanilla JS)** - Arhitectură pe componente și arhitectură modulară.

---

## Planuri de Viitor (Backend & Extindere)

Următorul pas în dezvoltarea proiectului este integrarea unui backend dinamic pentru gestionarea fluxurilor de date și a pacienților:

- [ ] **Backend în Python (FastAPI / Flask)** - Crearea unui API RESTful securizat pentru procesarea cererilor.
- [ ] **Sistem de Programări Online** - Gestionare dinamică a intervalelor orare disponibile și confirmare automată.
- [ ] **Bază de Date Pacienți & Panou Admin** - Stocarea securizată a solicitărilor de programare și evidența clienților.
- [ ] **Notificări Automate** - Integrare servicii de alerte (SMS / Email) pentru reamintirea programărilor.
- [ ] **Autentificare & Securitate** - Control al accesului bazat pe roluri (Admin / Staff) cu bune practici de securitate cibernetică.
